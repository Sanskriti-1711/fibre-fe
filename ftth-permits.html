How this page is safe

  • AI never flips status / readiness / required / blocks_construction.
  • Every AI response carries AI draft + disclaimer and is saved as PermitAiDraft for review.
  • When no LLM is configured the same actions return deterministic templates — the page stays useful offline.
  • Before you submit, verify the authority's current guidance in permits/ai/advisory.py checklists.

Env: PERMITS_LLM_URL + PERMITS_LLM_API_KEY + PERMITS_LLM_MODEL (OpenAI-compatible). No env → deterministic mode.
