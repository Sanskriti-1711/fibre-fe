How it is designed

Spans — the network is cut at every real structure (HDD pit, PDP, bend, branch, pull chamber), so each feature is one chamber-to-chamber sequence you can select and edit on its own.
Types — four construction classes, each with its own colour and stroke: Open Cut (excavated), HDD (drilled road crossings), Garden (hand-dug drop legs) and Aerial (never dug).
Aerial — drop legs inside an aerial zone are built aerial (no excavation) and published on their own layer; trench spans that run through a restricted zone are flagged AERIAL for review.
